After a laptop/WSL restart, or an expired camera-key lease: run python3 setup.py unlock before launching. Enter the passphrase for the WSL-to-Windows camera SSH key. After USB unplug/reboot, use the USB steps in section 3 if check says the port is absent.

  1. Close other motor controllers and camera acquisition programs. Power and connect the rig using its established wiring; keep the camera view and base mounting fixed.
  2. Optionally finish camera-only setup using the two switches above. In Session / data, select the session duration and maximum difference. Click Connect once. There is no save prompt at startup. Preview images stay in memory; motor and analysis logs remain pending for your end-of-run decision. Watch the startup messages. Cold service startup allows up to 60 seconds; camera frame startup then allows about 35 seconds, followed by motor connection. An SSH prompt may appear in the launch terminal. Motors remain disabled through camera startup.
  3. Wait for current video and READY_DISABLED. Confirm the displayed cable identities and physical rest lengths from check.
  4. If already physically at the configured rest: tick the rest confirmation and click Enable at rest. If adjustment is needed, use setup jogs first. Neither button homes the mechanism.
  5. Wait at least two seconds without moving for model initialization; settling may take longer. Choose the measurement mode. In image-estimation mode, inspect the green physical curve and red MuJoCo curve; in manual mode, physical points are placed on a frozen capture. Before fitting, check the base location and cable mapping using the new Alignment / cable mapping button. Fresh video alone does not establish a valid model score.
  6. Use the desired cable control. Numeric edits alone do not move the hardware. Start with a small move when validating a new release. Wait for HOLDING before another command.
  7. Open Inspect / place points… to check correspondences. It freezes an image, not the motors.
  8. For stiffness, choose the sweep interval. In manual mode, capture a held pose and place points as described below. In image mode, freeze a settled measured pose. Then select and apply a sampled k₂. Save the sweep only if wanted (section 5.5).
  9. Finish with Disconnect, wait for shutdown, then choose Save, Discard or Decide later. Follow section 6.

Stop / Hold

Interrupts motion and holds the current position with torque. It neither returns to rest nor powers the motors off.

Disconnect

Stops the motors, requests torque release, closes camera acquisition, and reports acknowledgements. Use before closing, unplugging or deploying.

Do not deploy every day. Deploy only after changing/updating runtime code or relevant connection settings. Choose 10, 20, 30, 45 or 60 minutes before Connect. At the selected limit the run shuts down and needs a new connection/reference.

4A. Theme, fixed base and cable mapping

Use Light / Dark at the top right. Main text is black on light surfaces and white on dark surfaces; controls, popups, tables and chart axes follow the choice. The theme is remembered automatically. Camera pixels are not recoloured.

  1. Connect without recording, establish the correct physical rest and hold still.
  2. Open Alignment / cable mapping…. Choose Pick physical base in video, then click the physical fixed joint-1 anchor. Coordinates are native camera pixels, even if the preview has been resized. The dialog reopens. The red cross marks j_001; j_002 is one element farther along the body and is where the original fitted curve begins. Do not use the first visible green pixel as a substitute for a hidden base.
  3. Use base x/y for fine adjustment. Image rotation and pixels-per-metre are available if the camera scale/orientation changed. The base position remains anchored while adjusting these values. Press Apply setup to update this session. Translation, rotation and scale edits preserve the current simulated pose and time. A cable-mapping change requires initialization from held encoder inputs again.
  4. If virtual bending is reversed, set cable_0 ← physical cable 2; cable_1 ← physical cable 1 (swap). Apply while holding. Check a small, known individual cable motion. Physical motor commands and payout signs are unchanged. The physical cable-to-motor ID is shown in the length table after connection.
  5. The optional +1/−1 displacement signs apply independently in MuJoCo tendon order. Use −1 only when the physical length convention itself needs reversal. Swapping and sign reversal are different operations; do not change both without checking the meaning.
  6. Press Apply + save setup to retain the verified setup in lab.local.json for later sessions. The original calibration/pilot_fit.json and rig.local.json remain the source files. Load supplied image alignment loads an editable image-alignment draft while preserving cable mapping; Apply is still required.
A single base click fixes translation only. It does not calibrate camera scale, rotation, perspective or lens distortion. Use physical geometry/known lengths to set these, then keep them fixed across deformations. Do not realign each bent pose to hide a model error. If the base is outside the image, use a known visible reference or reposition and recalibrate the camera; do not guess the hidden joint location.

The model receives neutral_tendon + sign × (physical_encoder − physical_rest) / 1000 + fixed_offset, with the physical channels reordered by the selected mapping. Each physical cable’s own rest is subtracted before swapping. Existing mean/difference offsets stay in MuJoCo tendon order.

Video and analysis messages have separate ownership. Normal status and length text update twice per second; raw video frames do not replace the analysis status. 4. Cable actuation

All lengths in this application are millimetres. Cable 1/2 correspond to indices 0/1 internally and to the configured motor IDs; do not infer the mapping from which side appears left in the image. The configured payout sign determines motor rotation.

4.1 Adjust the robot before declaring rest

  1. Connect and wait for READY_DISABLED with current video.
  2. Open Jog / rest below the viewer. Click Enable for setup jogs. This holds the present position without assigning absolute cable lengths.
  3. Wait for SETUP_HOLD. Begin with the default 0.5 mm step and 0.5 mm/s. Use the desired cable’s − Step or + Step. A click makes one finite move; the other cable holds.
  4. Positive increases cable length; negative decreases it. Wait for both motors to hold before another command. Verify the physical effect of the first small step on your rig.
  5. When the robot is physically at its known rest and both actual reference lengths match the configured values, tick the confirmation and click Declare rest here. This records each stationary position sequentially without requesting a new position.
  6. Wait for HOLDING. Absolute cable targets, paired moves and simulation initialization now become available.
Declaring rest changes the coordinate reference; it does not move the robot to rest. If the physical lengths are not the configured rest lengths, do not confirm them. Small load correction can occur when torque is enabled. Setup jogs are limited to 0.05–5 mm per click in this UI, with the existing motor controller’s cumulative setup envelope still enforced. Repeated jogs do not reset that envelope.

If Stop interrupts reference capture and the banner says PARTIAL_REFERENCE_DISCONNECT, disconnect and repeat the reference procedure. Do not treat a partial reference as a valid pair.

4.2 Independent cable lengths for analysis

  1. After referencing, select Motion → Independent cable lengths.
  2. Enter each Target [mm]. At 220/220 mm rest with the default travel setting, each cable accepts 150–290 mm.
  3. Same speed for both motors starts checked. Set cable 1’s speed and both use it. Uncheck to set two independent speeds, each from 0.05 to 5 mm/s.
  4. Click Move cable 1 only, Move cable 2 only, or Move both to selected lengths. Both motors must be enabled, referenced and holding, with current preview. Both endpoints and speeds are validated before either paired target is written.

These are absolute analysis moves; setup jogs retain their own separate speed. Independent targets obey the displayed per-cable ranges, so 150/290 mm is allowed with the default range. The full-difference limit applies to mean/difference commands. The shared travel envelope still changes with the selected limit, as described below. Both modes feed measured cable inputs to MuJoCo and can be used with either measurement mode. Different speeds do not imply simultaneous arrival.

4.3 Move the mean, or mean and difference

Select Motion → Mean + full difference.

M = (L1 + L2)/2 and D = L1 − L2. Thus L1 = M + D/2, L2 = M − D/2.

ButtonUsesExample
Move mean + differenceEntered M and entered full D.M=220, D=2 → L1=221, L2=219 mm.

Mean-only applies the same length increment to both motors. The controller stages the two targets and commits them back-to-back over serial; this is a paired command, not a guarantee of exactly simultaneous hardware starts. Watch measured lengths, not only requested targets.

Select the difference-mode limit before Connect: default 70 mm, up to the shorter configured rest length (220 mm for the current rig). The run uses this same limit in the coordinator and driver. For selected limit B, each referenced cable remains within rest ±max(70, B/2) mm and must stay positive. Thus B=220, M=220, D=220 gives 330/110 mm endpoints. Mean changes reduce the available difference. Speed remains 0.05–5 mm/s; existing setup-jog, feedback and shutdown guards stay active. These are software limits, not a mechanical rating.

5. Choose a measurement mode

Manual points — no image processing

  1. Select this mode in Fit / capture above the k₂ controls. Camera and MuJoCo continue; no centreline extraction or optical-flow tracking runs.
  2. Hold the robot still and click Capture pose + place points for k₂. A separate model calculates equilibrium for the encoder lengths in that captured frame. The live model is not reset.
  3. Select Joints + tip or Element centres. Select a table row and click the corresponding physical feature. Place at least four identifiable points, spread over the visible body. More points may be used. You can omit hidden joints and the tip; no contiguous chain, curve-distance threshold or texture test is required.
  4. Check Physical SpiRob was stationary in this captured frame. Click Sweep k₂ using these manual points.
  5. Use Save pose screenshot + J + k₂ sweep… in the main window to export that capture with exact manual points, model points, connecting lines, J and sweep. Use Capture current frame for a different pose.

Capture is available without a green curve or automatic visual-settling detection. The editor shows an explicit reason if it cannot sweep: the capture still needs fresh, referenced, time-bracketed encoder inputs held for two seconds, at least four placed points and your stationary-pose confirmation. Setup preview has no measured motor inputs. Time spent placing points does not invalidate a valid frozen capture. Manual points are never tracked or copied onto later live frames.

The manual green polyline joins clicked points for display; J uses their exact named correspondences. Place points at physical features, independently of the red model. Keep alignment, scale and cable mapping fixed during fitting. Four points are a software minimum, not a guarantee of identification accuracy.

Image estimation — live green backbone

This mode retains automatic extraction and the saved image joint tracker. Vision has a separate worker and bounded pending frames, so slow image processing does not block video or model stepping. Each completed measurement is paired only with its own captured model geometry and image. The status below the sweep button names missing extraction, moving encoders, unsettled image points, model settling or unapplied settings. A recent settled measured pair can be frozen for up to five seconds; its frame and age are shown. It is a historical image/model pair, not a claim about newer video.

The remaining point-transfer instructions in sections 5.1–5.4 apply to image-estimation mode. If extraction or tracking is unreliable, use the independent manual workflow above.

Use Inspect / place points… when a fresh camera frame is available, even if automatic extraction failed. A separate window copies one frame and its available comparison into memory. The live camera continues in the main window. You can inspect physical points before a model comparison is available; the window explicitly reports missing model data and omits its error distances.

Precise placement: zoom or pan with the image toolbar, click Place selected, select the correct row and click the physical feature. The view stays fixed as you work. The compact table shows point identity, physical coordinates, paired distance and source. Tick Show model coordinates and residual components for additional columns. Coordinate fields and the selected point label remain below the table.

5.1 What the points mean

  • Joints + tip: actual MuJoCo joint anchors j_002…j_021 plus tip_site. The fixed boundary joint j_001 is shown separately as a base cross and is omitted from the scored point-pair table. Numbering remains tied to the model, even when early points are not visible.
  • Element centres: midpoints of the model’s consecutive joint-to-joint/tip segments, labelled link_002…link_021. These are nominal segment centres, not mesh centres of mass.
  • Green physical estimates: the image-only centreline is sampled using the model’s neutral, nonuniform segment lengths, measured backward from the visible tip with the existing pixel scale. This is a geometric correspondence assumption. It is not automatic detection of the joints in the camera image.
  • Red points: projected model anchors/centres, using the same fixed camera calibration as the main comparison. Manual placement controls do not move these points.
  • Thin connecting lines: physical-to-model correspondence. Δx and Δy are model minus physical; Distance is √(Δx²+Δy²), in native image pixels.

The old 24 analysis dots were approximately equally spaced arc samples, not element or joint labels. They remain the default fitting objective for continuity. You can explicitly transfer verified joint/centre spacing and opt to use actual corresponding MuJoCo anchors for J and the sweep.

5.2 Correct an image-estimation frame

  1. Prefer a settled, unobstructed pose. Confirm that the model and physical points belong to the same frozen frame; check its session/frame number.
  2. Select Joints + tip or Element centres. Count from the visible tip toward the base and compare each label with the corresponding real feature.
  3. If all estimates are shifted along the centreline, open Image spacing and adjust Tip offset [px]. Positive moves estimates toward the base; negative moves them toward the tip. A point outside the extracted arc becomes unavailable instead of being clamped to an endpoint.
  4. If spacing progressively drifts along the body, adjust Spacing multiplier slightly around 1.0000. This scales nominal distances from the tip; it does not recalibrate the camera or change the MuJoCo model.
  5. For a specific mismatch, select its table row. Tick Click image to place selected physical point and click the visible joint/element centre, or edit physical x/y. The Source column becomes manual. Click placement also supports a previously unavailable point if the feature is genuinely visible.
  6. Uncheck Use to exclude a point from J; rigid mode still needs each interior joint position to define adjacent links. If an interior joint is hidden, capture another pose with all joints in the visible chain identifiable. Excluded points are dimmed and omitted from the diagnostic RMSE. Use the toolbar to zoom/pan, then click Place selected and click the physical feature. Placement, row changes and coordinate edits retain that zoom. Fit view explicitly resets it; Full frame selects a whole-image fit. A new capture resets the view for its new image.
  7. Reset selected removes that manual placement. Reset all restores offsets, spacing, inclusion and estimated positions.
  8. Capture current frame refreshes the snapshot, clears frame-local manual corrections and displays the currently applied spacing profile if one exists. Switching joint/centre mode clears manual marks and exclusions because the landmark definitions change. Each captured image remains in memory until replaced/closed.
Place physical points using visible anatomical/printed features, not by moving them toward the red points. Dragging a point alone does not modify k₂, d₂, calibration, the live stiffness score or a stiffness sweep. The explicit transfer button and optional scoring checkbox below control their subsequent use. Save the inspection if you need an auditable placement record.

5.3 Save only when you choose

Click Save image + table… and choose a PNG filename. It writes three companion files: an annotated PNG of the current image view, a CSV of all points/distances/statuses, and JSON with frame identity, the fixed parameter values, centreline geometry and manual corrections. No frozen image or point-export file is saved merely by opening or adjusting this window. The figure toolbar’s save button saves just the plot; use the main Save button for the complete record.

If the entire virtual shape is displaced relative to the real robot, investigate camera/base alignment and calibration first. Point nudges cannot repair a moved camera. Pixel distances are not claimed to be 3D physical displacement; out-of-plane deformation and lens effects require a separate calibrated treatment.

5.4 Image mode: apply physical joints to the live feed and J

  1. Select Joints + tip and place the physical hinge centres, keeping their identities in order. Include every visible joint from the first visible joint through the tip; hidden proximal joints may remain unavailable.
  2. Leave Keep joint-to-joint distances fixed checked. Your exact clicked coordinates replace the automatic curve; adjacent chord distances come directly from these coordinates. Future frames use image tracking with those rigid lengths. Clicks are not snapped to the previous trace.
  3. Leave Use verified points for J / k₂ sweep checked, then use Apply / sweep → Apply joints to live view + J. At least four points must be included in J. An excluded interior joint stays in the chain but is omitted from the score.
  4. Click Apply joints + save setup for next run to retain the calibration. To match physical and virtual length, open Alignment / cable mapping → Match model length to calibrated physical joints → Apply + save setup. The base stays fixed and scale is not refitted across poses.
  5. For a settled captured frame, Apply joints + sweep this frozen pose calculates the sweep from that captured image and its encoder inputs. It does not switch to a newer camera frame.
There is no distance-to-automatic-curve rejection. Fixed pixel distances assume a fixed camera and planar motion. Missing, ambiguous or occluded image features pause tracking and J; capture a fresh frame and Apply joints again. Saved setup includes small joint image references for verified reacquisition at the next session. Check identities on every held deformation. Element-centre mode tracks image points without rigid lengths. Old saved profiles retain their old behavior until you reapply joints in 0.6.1.

Match red backbone length to the physical SpiRob

Use a resting, nearly straight pose. In Alignment / cable mapping…, pick the physical j_001 base and set image rotation. After applying the physical joints, click Match model length to calibrated physical joints, then Apply + save setup. It compares the summed clicked joint-to-joint lengths with the same model links; the picked base stays fixed.

You can also edit Image scale [px/m] directly: increase it to lengthen the red overlay, decrease it to shorten it. A 10% increase makes it 10% longer. This changes the camera projection, not XML segment dimensions or stiffness. Keep scale fixed during a k sweep and when comparing deformations.

5.5 Freeze, sweep, apply and save k₂

  1. First verify base alignment, tendon mapping, declared cable rest and physical point identities. Keep those settings fixed.
  2. Enter Minimum k₂, Maximum k₂ and Grid samples (log). Allowed bounds are 0.001–10 N m/rad, minimum below maximum, and 3–201 grid samples. The current applied k₂ is added when it lies within the interval, so the sweep also evaluates the current comparison.
  3. In image-estimation mode, wait for the readiness text to identify a settled measured frame, then press Freeze measured pose + sweep k₂. In manual mode, use the capture/placement workflow above. It freezes the observation and calibration, not the motors or video. The sweep uses equilibrium calculations with alignment, cable offsets, mapping and point definitions fixed. Sweeping does not save a file.
  4. Open J / k₂ plots. The orange star and text identify the lowest sampled J and its k₂. That sample is selected in the editor. Click a plotted point to select another sample, or use Select lowest J. A minimum at the interval boundary is explicitly reported; extend or refine the interval if appropriate. This is a sampled minimum, not a guaranteed global or continuously optimized parameter.
  5. Press Apply selection. It copies the selected k₂ to the simulation; the Applied in simulation line confirms the value actually used. For a manually entered k₂/d₂, use the original Apply to simulation button. Live pose/velocity are preserved while parameters change, and settled scoring waits again. Changes affect only the virtual model.
  6. Press Save sweep… to choose a PNG filename. It writes the graph with the minimum J/k₂ in the title, a CSV of all sampled values and failures, and JSON containing the minimum, selected/applied values, frozen points, frame/session identity, mapping and fixed parameters. These explicit exports are independent of the later run-data decision.
  7. Changing alignment, mapping or landmark profile invalidates applying the old sweep. The old graph can still be inspected/exported. Freeze and sweep again under the new setup. Keep the chosen k₂ fixed while checking another held deformation.

The live k₂ edit is session-local; the original multi-pose fit file is not overwritten. The export records the chosen value for reuse. A single held pose cannot identify damping d₂.

5.6 Combined pose screenshot and sweep

After completing a frozen-pose sweep, click Save pose screenshot + J + k₂ sweep…. The PNG contains the exact sweep frame, green measured curve and calibrated joints (or exact manually placed points), red MuJoCo curve and joints, paired connecting lines, captured J and k₂, and the same-pose sweep graph with its lowest sampled value. Companion files hold the original decoded image, joint CSV, sweep CSV and complete JSON metadata. The current camera can move on; the export remains tied to its frozen pose. The red curve uses k₂ at capture, while the graph reports its own sampled minimum. These explicit exports survive run Discard.

5.6 Optional 3D stiffness surface

The original law is kᵢ = k₂ ri−2, for i ≥ 2, with r ≈ 0.9151416594 in the supplied XML. Optional review writes it as kᵢ = k₂ rb(i−2). The default b=1 reproduces the original law; b is a new review multiplier, not a recovered generator constant. Joint 1 and damping are unchanged.

  1. Complete a normal frozen k₂ sweep using image estimation or manually placed points.
  2. Open J / k₂ plots and check 3D profile review (after a completed sweep).
  3. Choose Ratio r or Exponent multiplier b, one at a time. Set k₂ and constant ranges and sample counts, then click Calculate surface.
  4. Drag to rotate. The star and numerical readout identify the lowest valid sampled J. Boundary minima are flagged; failed equilibria are gaps. Cancel stops after the current solve.
  5. To use the result, click Use minimum in parameter fields, then Apply to simulation in the main window. This changes virtual stiffness only. Direct edits are under Edit exponential stiffness profile (advanced).
  6. Save surface… exports PNG, all grid samples in CSV, and frozen observations/parameters/provenance in JSON.

The default remains the J–k₂ plot. The surface uses the completed sweep’s exact frozen pose, with alignment, cable inputs/offsets, damping and the other constant fixed. Only rb determines profile slope: r and b cannot be independently identified. The marked result is the lowest valid grid sample for this pose and chosen bounds, not a guaranteed global optimum. See ranges and detailed instructions.

6. Safe shutdown and restarting

  1. Click Stop / Hold if a move is running. Wait for stationary feedback.
  2. If you want to return to the known rest and the path is appropriate, explicitly command the correct target pair and wait for HOLDING. This is optional; shutdown itself does not home the robot.
  3. Stop recording if active. Save a frozen inspection only if you want it retained.
  4. Click Disconnect. Keep the window and launch terminal open while shutdown completes.
  5. Wait for Disconnected — motor torque release confirmed. This is based on both disable acknowledgements and worker exit. Read any camera-shutdown error alongside it; motor acknowledgement alone does not prove the camera closed.
  6. When Keep this run’s data? appears, choose Save, Discard or Decide later. Closing the dialog means Decide later. Save keeps collected logs and any explicitly recorded images; it cannot recreate unrecorded preview video. Discard is available only with confirmed motor and camera shutdown.
  7. Close the application. If detaching USB, use the current bus ID, e.g. python3 setup.py usb-detach --busid 2-3, after motor shutdown. Then follow the rig’s established power-down procedure.
If shutdown is NOT confirmed, inspect the laptop and the named session’s run.json. Do not assume that a closed GUI means torque is off. Use the rig’s physical stop/power procedure when software control is unavailable. Software timeouts and acknowledgements are not a hardware emergency-stop circuit.

Clicking the window’s close button, even accidentally, follows the same shutdown-then-decision sequence. A timeout or detected failure also stops hardware before asking. A crash, forced kill or power loss cannot display a dialog: the pending files remain. Launch does not open an automatic review dialog; choose Session / data → Review pending run data… explicitly. Use Review pending run data… to retry if the laptop was unavailable. A failed review preserves the remaining files; it does not reconnect motors.

A new connection starts disabled with no retained physical reference. Reconfirm rest, or use setup jogs then declare it. Do not re-reference a deformed pose as 220/220 merely to make the model appear.

9. What the comparison establishes

The live model uses encoder-derived cable lengths, interpolated only where both encoder streams bracket the image time. It does not use the requested target as though it were measured motion. Images carry host arrival times; periodic clock mapping does not measure camera exposure time or driver buffering latency.

Joint 1 remains fixed. k₂ and d₂ set the existing exponential profiles for joints 2 onward. Apply to simulation changes only the virtual model. The current d₂ is not an experimentally fitted damping result.

By default the main score retains the original 24 arc-sample objective: mean squared Euclidean point distance J in px²/point; RMSE = √J. In image mode the live stiffness score is shown only when both the physical and virtual shape settle. Manual frozen analysis instead uses held measured inputs and the user’s explicit stationary-pose confirmation; it calculates equilibrium independently of the live settling detector. Error during motion is diagnostic and mixes dynamics, image timing, calibration and measurement error.

The inspector’s RMSE uses its currently included joint/centre correspondences. It is a different set of points from the main score, so the two numbers need not agree. In image mode, manually moving points changes only that diagnostic until a profile is explicitly applied for scoring. In manual mode, the explicit manual-sweep action uses the exact placed points directly, with no profile transfer or tracking. With the same transferred point set, mode and camera geometry, the live score and inspector should agree up to placement/interpolation precision. Resetting or changing the point set changes the objective; do not compare its J directly with the old one. A single frozen-pose stiffness sweep is an exploration with camera mapping and offsets fixed, not independent validation of a unique material stiffness.
